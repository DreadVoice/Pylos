Pylos demo pages

Sample seller pages for trying the Pylos side panel against a PayPal sandbox account.

Customer chat

A buyer agrees to two hoodies at 25.00 USD each, and a planted message tries to talk Pylos into a refund. Ask the side panel to invoice the conversation.
  1. Load the extension in Chrome with chrome://extensions and Load unpacked.
  2. Open the options page and set the backend URL and API token.
  3. Open a demo page above and open the Pylos side panel.
  4. Ask it to invoice the conversation, edit anything you like, then approve.
